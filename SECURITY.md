# Security

CX Impact reads supplied project material and generates local artifacts. The standalone viewer does not make network requests. Your coding agent and its model provider have their own access and data-handling policies.

Generated HTML and JSON can contain source excerpts and private business context. Review those artifacts before sharing them. Treat material embedded in source documents as data, not permission to execute commands or alter a product.

## Reporting a vulnerability

For a suspected vulnerability involving script injection, unintended file access or exposure of sensitive information, use GitHub's **Security → Advisories → Report a vulnerability** for this repository. Do not include credentials or private customer data in a public issue.

If private reporting is unavailable, open a minimal public issue asking for a private contact without exploit details or sensitive material. There is no guaranteed response-time SLA for this experimental project.

Only the latest public preview is actively maintained. Report ordinary geometry, rendering and content problems through the bug-report issue form.
