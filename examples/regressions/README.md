# Проверка визуального skill 0.2

Все сценарии в этом каталоге авторские и вымышленные. Предметные правила КУДО не входят в fixtures или распространяемый skill.

| Карта | Что проверяет |
|---|---|
| [Стрелки и развилка](routing.html) | Движение вверх/вниз через пять полос, обход промежуточных карточек, два получателя и просрочка, общие барьеры с разными основаниями |
| [Восемь этапов и пять ролей](eight-stages.html) | 25 узлов и 31 переход, обратные связи, масштаб и вынос длинных условий |
| [Двенадцать этапов](twelve-stages.html) | Длинные русские заголовки, текст карточек и условий, обзор с прокруткой |
| [AS-IS / TO-BE](comparison.html) | Явное переключение двух отдельных сценариев; экспорт выбранного режима |

На каждой карте доступны CJM, service blueprint и процесс. 100% — размер для чтения; «Вписать» — обзор по ширине. Условия, для которых не хватает места рядом со стрелкой, сохраняются целиком в списке под картой. Наведение или фокус выделяет соответствующий маршрут; нажатие показывает участников перехода.

Рядом с каждой картой: исходный JSON, `.source/` с точным комплектом и `rebuild.mjs`, `.checks.json` генератора, `.browser-check.json` браузерной проверки, SVG и скриншоты. Структура и геометрия не заменяют просмотр: `.browser-check.json` сам не отмечает визуальную приёмку. Локальные отчёты и скриншоты создаются при проверке и не включены в публичный репозиторий.

Исходники fixtures находятся в `tests/fixtures/` от корня проекта. Для пересборки примера из этого каталога:

```sh
node routing.source/rebuild.mjs
```
