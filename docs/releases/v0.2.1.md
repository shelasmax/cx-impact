# CX Impact v0.2.1 — English and Russian maps

The bicycle workshop now has matching English and Russian editions, each with customer journey, service blueprint and experience-process views. Both READMEs show three full screenshots with descriptive headings.

- Set `locale: "en"` or `"ru"` for viewer controls, evidence labels, details, accessibility labels and SVG exports. Existing JSON without locale retains Russian. Authored scenario content is not machine-translated by the renderer.
- The English example preserves the Russian example's stage IDs, roles, evidence statuses and process connections, including return without repair when the estimate is declined.
- No new runtime dependency; Node.js 18+ and the common Codex skill package are retained.

## Install or try

Download `cx-impact-0.2.1.zip`, extract it and copy `cx-impact/` into your project's `.agents/skills/`. Preserve an existing installation before upgrading, then start a fresh Codex session and invoke `$cx-impact`.

Download and open `bicycle-service-demo-en.html` for English or `bicycle-service-demo.html` for Russian. The matching JSON files are editable. `SHA256SUMS` covers the package and both demos.
