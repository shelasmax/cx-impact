# CX Impact v0.5.0 — First use, map updates and JSON checks

This release helps product managers and analysts get a first map and update it when new material arrives. The single portable package still creates customer journey maps, service blueprints and experience-process maps as standalone HTML with editable JSON and SVG export.

## What changed

- Three worked exercises in [English](https://github.com/shelasmax/cx-impact/blob/v0.5.0/skills/cx-impact/references/quickstart.md) and [Russian](https://github.com/shelasmax/cx-impact/blob/v0.5.0/skills/cx-impact/references/quickstart.ru.md): a target service from requirements, a documented current process, and a revision of an existing map. Each includes original fictional source material, a prompt, authored JSON and limitations. Generated results are saved outside the installed skill.
- An explicit revision workflow preserves unchanged IDs, source history and unaffected content, exposes unresolved contradictions, and saves a separate result bundle and change note. Custom snapshots stay separate from the installed package.
- `node scripts/render-map.mjs --check map.json` validates structure and automated geometry without writing output files. Errors return a nonzero exit code; warnings remain visible. This does not replace visual inspection or human review of the map's meaning.
- Repository development materials now include a five-person pilot protocol, four original synthetic comparison tasks and a local Codex evaluation runner. These materials are protocols, not completed customer research or evidence of superiority over a short prompt.

The map format remains `version: 1`. Existing viewer behavior, designs and standalone operation are preserved. No runtime package, server or external rendering service was added. Codex remains the tested local target; this release adds no model-testing claim for other agents.

## Install, upgrade and rollback

Install from your project directory:

```sh
npx skills add shelasmax/cx-impact --skill cx-impact
```

For a version-pinned installation, extract the attached `cx-impact-0.5.0.zip` and copy the whole `cx-impact/` directory to your agent's skill location. Installation and upgrade guides: [English](https://github.com/shelasmax/cx-impact/blob/v0.5.0/docs/installation.md) · [Русский](https://github.com/shelasmax/cx-impact/blob/v0.5.0/docs/installation.ru.md).

Back up the installed directory before replacement and start a fresh agent session after upgrading. Keep existing maps and customized `.source/` snapshots; they retain their embedded renderer. To roll back, restore the saved directory or install the previous v0.4.0 archive. Previous release tags and assets are preserved.

The release attaches the skill archive, English/Russian bicycle HTML demos and JSON sources, and `SHA256SUMS`. Human pilot results, private maps and raw evaluation logs are not publication inputs.
