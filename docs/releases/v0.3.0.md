# CX Impact v0.3.0 — Two designs and animated path walkthroughs

The original green **Classic** design remains the default. Choose **Graphite Field Notes** for the new editorial typography, neutral surfaces and terracotta accents. Both designs work across customer journey maps, service blueprints and experience-process maps.

- **Independent appearance controls:** Classic / Graphite and Light / Dark / System. Choices persist locally when browser storage is available. SVG exports retain the chosen colors and typography.
- **Optional path walkthroughs:** Play, Pause, Previous, Next and Reset. CJM and blueprint walkthroughs highlight stages; process walkthroughs follow authored connections, pause for explicit branch selection and stop at endpoints or cycles. Reduced motion provides static steps. Animation illustrates reading order, not actual execution or service timing.
- **Details and exports:** modal details with keyboard focus return; complete static SVGs exclude temporary highlights and animation. JSON exports remain unchanged.
- **Compatible package:** the JSON format stays at version 1. No new runtime dependency, server or external rendering service. Refreshed English and Russian demos and portable source bundles are included.

## Install or upgrade

Download `cx-impact-0.3.0.zip`, extract it and copy `cx-impact/` into your project's `.agents/skills/`. Preserve your existing installation and custom map snapshots before upgrading. Start a fresh Codex session and invoke `$cx-impact`.

Existing standalone HTML files keep their embedded viewer. Regenerate from the original JSON with the updated skill to get appearance controls and walkthroughs; keep customized snapshots separate. To roll back, restore your saved installation or reinstall the v0.2.1 package. Existing release tags and assets are preserved.

Download and open `bicycle-service-demo-en.html` for English or `bicycle-service-demo.html` for Russian. The matching JSON files are editable. `SHA256SUMS` covers the skill archive and both demo pairs.

## Verification and scope

The release process runs renderer tests, publication-integrity checks and an extracted-package render/rebuild smoke check. Optional local Chrome checks cover both designs, both color modes, three views, native/fit sizing, branch playback, reduced motion, keyboard details and reopened SVG exports. See the [verification scope](https://github.com/shelasmax/cx-impact/blob/v0.3.0/docs/verification.md) for the exact coverage and [GitHub Actions](https://github.com/shelasmax/cx-impact/actions/workflows/checks.yml) for hosted results.

CX Impact remains experimental and locally tested with Codex. Claude Code and other browser engines are untested. Automated checks do not establish semantic correctness or human acceptance of a map. See the [changelog](https://github.com/shelasmax/cx-impact/blob/v0.3.0/CHANGELOG.md).
