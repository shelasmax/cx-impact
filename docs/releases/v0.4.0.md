# CX Impact v0.4.0 — Branded exports and portable installation

The current CX Impact logo now travels with every SVG export. It is embedded as the original PNG below the complete map legend, preserving its colors and proportions in Classic and Graphite, light and dark. Exported JSON remains the original map data. Classic is still the default design.

Install from your project directory and choose an agent:

```sh
npx skills add shelasmax/cx-impact --skill cx-impact
```

The existing Skills CLI installs the same canonical package for Codex, Claude Code and OpenCode. DeepSeek Harness can use the shared `.agents/skills/` directory via the `universal` installer target or a manual `.dsh/skills/` copy. No CX Impact npm package, adapter, service or runtime dependency was added.

Both READMEs now have localized promotional artwork, actual generated examples and clear platform status. Full installation and upgrade instructions are available in [English](https://github.com/shelasmax/cx-impact/blob/v0.4.0/docs/installation.md) and [Russian](https://github.com/shelasmax/cx-impact/blob/v0.4.0/docs/installation.ru.md).

Codex remains the tested local target. Package installation, resource integrity and renderer/rebuild checks passed in isolated project copies. OpenCode 1.15.12 discovered the skill locally. Claude Code and DeepSeek Harness compatibility follows their official documentation; no model-driven end-to-end test is claimed for Claude Code, OpenCode or DeepSeek Harness. See the scoped [verification record](https://github.com/shelasmax/cx-impact/blob/v0.4.0/docs/verification.md).

## Upgrade and rollback

Back up your installed skill, then rerun the installer or replace the whole directory with `cx-impact-0.4.0.zip`. Start a fresh agent session. Existing standalone maps retain their embedded renderer: generate a copy from JSON to adopt branded SVG exports. Keep customized `.source/` snapshots separate.

English and Russian HTML demos, original JSON files and `SHA256SUMS` are attached. SVG files include the embedded logo and are about 1.2 MB larger. The product remains an experimental preview. Previous release tags and assets are preserved; reinstall a saved archive to roll back.
