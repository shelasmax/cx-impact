# CX Impact v0.3.1 — Current logo in every theme

Classic and Graphite now show the current CX Impact logo from the repository's brand assets. The old placeholder symbols are removed. The original logo retains its colors and ivory backing in both light and dark modes.

The logo is embedded in each standalone HTML file and portable source snapshot, so it works offline without additional files or requests. This adds about 1.2 MB to each HTML map. Map data, geometry, appearance controls, path walkthroughs and exports are unchanged.

Download `cx-impact-0.3.1.zip` and replace your installed `cx-impact/` skill directory after preserving any customizations. Start a fresh Codex session. Existing standalone maps keep their embedded viewer; regenerate a copy from JSON to update their logo.

English and Russian interactive demos, their original JSON files and `SHA256SUMS` are included. See the [verification scope](https://github.com/shelasmax/cx-impact/blob/v0.3.1/docs/verification.md). CX Impact remains experimental; Claude Code and other browser engines are untested.

The v0.3.0 release and tag are preserved. Restore a saved installation or reinstall its archive to roll back.
