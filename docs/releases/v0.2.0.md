# CX Impact v0.2.0 — visual maps for AI-assisted product work

The first public preview of CX Impact: one agent skill that turns a service description, product documents, research or relevant code into a customer journey map, service blueprint and experience-process map.

## In this release

- Standalone interactive HTML with three complementary views of one scenario.
- Explicit AS-IS / TO-BE and separately requested comparison.
- Visible requirements, observations, hypotheses, proposals and unknowns; shared barriers and sources across views.
- Routes around unrelated cards, full decision conditions, natural 100% scale and fit-to-width.
- SVG of the entire active view, source JSON and a reproducible local renderer snapshot.
- MIT license, English/Russian project documentation and regression fixtures.

## Install

Download `cx-impact-0.2.0.zip`, extract it and copy the `cx-impact` directory into your project's `.agents/skills/`. Start a fresh Codex session and invoke `$cx-impact`. Rendering requires Node.js 18+ and no external Node packages.

To try the output first, download `bicycle-service-demo.html`, save it and open it in a browser. The example is fictional. `bicycle-service-demo.json` contains its editable source. `SHA256SUMS` records the release-asset checksums.

## Maturity and verification

This is an **experimental preview**, not a claim of production readiness. The viewer UI is currently Russian. Claude Code has not been tested. Dense processes may need separate maps or numbered condition callouts; drag-and-drop and complete BPMN are not implemented.

The release includes 18 renderer/geometry tests, packaging checks and a smoke test of the extracted skill. Local browser checks covered the three views at laptop and desktop sizes, SVG/JSON round trips and reproducible rebuilds. Automated checks do not prove semantic correctness or superiority over a short prompt.
