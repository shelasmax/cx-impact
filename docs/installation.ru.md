# Установка и обновление

[English](installation.md) · [README на русском](../README.ru.md)

CX Impact использует единый переносимый пакет `SKILL.md`. Агенту нужны чтение и запись файлов и доступ к командной строке; рендереру — Node.js 18+ без внешних пакетов. Доступ к модели настраивается в самом агенте. Готовый HTML работает в современном браузере без сервера и сетевых запросов.

## Установка через npx

В каталоге своего проекта:

```sh
npx skills add shelasmax/cx-impact --skill cx-impact
```

Выберите агента и область установки. Для установки копий в текущий проект без диалога выбора:

```sh
npx skills add shelasmax/cx-impact --skill cx-impact --agent codex claude-code opencode --copy --yes
```

Можно указать только одного из этих агентов. Добавляйте `--global`, только если нужна установка для всех проектов. `--copy` копирует полный пакет вместо создания символьных ссылок. После установки начните новую сессию агента.

Используется сторонний [Vercel Skills CLI](https://github.com/vercel-labs/skills); собственный npm-пакет CX Impact не нужен. Для `npx` требуются npm и интернет. Установка проверена с `skills@1.5.23`: для повторения этой версии установщика замените `npx skills` на `npx --yes skills@1.5.23`. Установщик позволяет отключить телеметрию через `DISABLE_TELEMETRY=1` или `DO_NOT_TRACK=1`. Это отдельный механизм, не связанный с автономным просмотрщиком карт.

## Выбор агента

| Агент | Каталог скилла в проекте | Вызов | Что проверено |
|---|---|---|---|
| Codex | `.agents/skills/cx-impact/` | `$cx-impact` | Проверенная локальная среда, установка и рендерер. |
| Claude Code | `.claude/skills/cx-impact/` | `/cx-impact` | Совместимость по документации и комплект установленных файлов; без запуска модели. |
| OpenCode | `.agents/skills/cx-impact/` через установщик; также поддерживается `.opencode/skills/cx-impact/` | Попросить использовать скилл `cx-impact` | Обнаружение скилла проверено локально; без запуска модели. |
| DeepSeek Harness | `.agents/skills/cx-impact/` или `.dsh/skills/cx-impact/` | Попросить использовать скилл `cx-impact` | Совместимость по документации; запуск harness не проверялся. |

### Claude Code

```sh
npx skills add shelasmax/cx-impact --skill cx-impact --agent claude-code --copy --yes
```

Структура с `SKILL.md`, справочниками, ресурсами и скриптами и вызов `/cx-impact` соответствуют [официальной документации](https://code.claude.com/docs/en/skills). Личная установка размещается в `~/.claude/skills/`. Адаптер, плагин и дополнительные поля frontmatter не нужны. Корневой `CLAUDE.md` репозитория предназначен для разработки самого скилла и не требуется при установке. По запросу пользователя поддержка описана на основании документации; успешный сеанс генерации с моделью не заявляется.

### OpenCode

```sh
npx skills add shelasmax/cx-impact --skill cx-impact --agent opencode --copy --yes
```

Согласно [официальной документации](https://opencode.ai/docs/skills/), OpenCode поддерживает собственный каталог и совместимые `.agents/skills/` и `.claude/skills/`. Попросите загрузить `cx-impact` через инструмент навыков и опишите карту. Не храните разные версии скилла сразу в нескольких распознаваемых каталогах. Локальная команда `opencode debug skill --pure` подтвердила обнаружение; это не проверка генерации настроенной моделью.

### DeepSeek Harness

Для общего каталога навыков в текущем проекте:

```sh
npx skills add shelasmax/cx-impact --skill cx-impact --agent universal --copy --yes
```

Цель `universal` записывает пакет в `.agents/skills/cx-impact/`. Это название цели установщика, а не адаптер DeepSeek. Альтернатива — скопировать весь распакованный пакет в `.dsh/skills/cx-impact/` в корне проекта.

[Официальная документация файловых навыков](https://deepseek-harness.github.io/deepseek-harness/en/reference/subsystems/skills) описывает оба каталога и доступ к ресурсам пакета. В конфигурации harness должны быть включены файловые навыки, инструмент их загрузки для модели и инструменты файлов и командной строки. Отдельный DSH-плагин для такого подключения не нужен. Сам harness для этого релиза не устанавливался и не запускался. Установка описана для проекта: глобальные пути установщика и пользовательской конфигурации DSH могут различаться.

## Ручная установка конкретной версии

1. Скачайте [cx-impact-0.6.0.zip](https://github.com/shelasmax/cx-impact/releases/download/v0.6.0/cx-impact-0.6.0.zip).
2. Распакуйте архив. Внутри один каталог `cx-impact/` с `SKILL.md`, ресурсами, справочниками, рендерером и лицензией.
3. Скопируйте **весь каталог** по пути из таблицы. Предварительно сохраните существующую установку.
4. Начните новую сессию агента в проекте.

При установке из репозитория используйте `skills/cx-impact/` из тега `v0.6.0`. Короткая команда `npx` использует репозиторий, а архив релиза фиксирует конкретную версию пакета. После скачивания ручной установке и рендереру реестр пакетов не нужен.

В релиз входит `SHA256SUMS`. На macOS сравните хеш архива со строкой в этом файле:

```sh
shasum -a 256 cx-impact-0.6.0.zip
```

Если скачаны все перечисленные файлы, проверьте их командой `shasum -a 256 -c SHA256SUMS`. В Linux используется `sha256sum`. Это проверка соответствия файлов, а не подписанное подтверждение происхождения.

## Первая карта

Например, в Claude Code:

```text
/cx-impact Создай целевую CJM и service blueprint онбординга этого продукта.
Используй документы проекта. Разделяй требования, гипотезы и неизвестные.
Сохрани автономный HTML, исходный JSON и комплект для пересборки.
Сделай содержание карты и интерфейс на русском языке.
```

В Codex начните с `$cx-impact`; в OpenCode и DeepSeek Harness — с «Используй скилл cx-impact». Укажите сценарий и текущий или целевой режим. Для черновика достаточно описания без кода. Для карты процесса попросите показать участников, передачи, решения и восстановление.

Можно запросить русский или английский. Агент задаёт `locale: "ru"` или `"en"` для интерфейса и пишет содержание на выбранном языке. Отсутствие locale сохраняет русский интерфейс старых JSON. [Пример на английском](installation.md#first-map-in-english-or-russian).

## Обновление, откат и удаление

Сохраните копию установленного каталога `cx-impact/`, особенно если меняли его. Повторите команду установки либо замените весь каталог новым релизом, затем начните новую сессию. Не смешивайте файлы разных версий. Для отката восстановите сохранённый каталог или архив предыдущего релиза.

Готовые карты — отдельные файлы. Сохраните их JSON и каталоги `.source/`. Для сохранения точного оформления конкретной карты редактируйте и пересобирайте её собственный снимок:

```sh
node map.source/rebuild.mjs
```

Для переноса карты на новую версию отрендерите копию её JSON новым рендерером под новым именем. Плоский JSON `version: 1` поддерживается; отсутствующий режим показан как неуточнённый. Старым пользовательским шаблонам нужны маркеры вставки из [описания формата](../skills/cx-impact/references/maps.md).

Для удаления удалите только установленный каталог `cx-impact/`. Для установленных через CLI копий команда `npx skills remove cx-impact` предлагает выбор области и агентов. Созданные карты сохранятся.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Скилл не найден | Путь из таблицы, точное имя `SKILL.md` и текущий проект сессии. Начните новую сессию. |
| Загружается другая версия | Проверьте дубли в проекте и личных каталогах и файл `VERSION` в архиве. |
| Команда Node недоступна | Установите Node.js 18+ отдельно: скилл этого не делает. |
| Агент не может сохранить или отрендерить карту | Проверьте доступность файловых инструментов и командной строки для выбранного каталога. |
| GitHub показывает код HTML | Скачайте файл и откройте его в браузере. |
| Мелкий текст | Используйте **100%** для чтения, **Вписать** для обзора и прокрутку внутри полотна. |
| Условия находятся под процессом | Рядом с маршрутом не хватило места. Полный текст сохранён; наведение или фокус подсвечивает маршрут. |
| Браузерный инструмент блокирует SVG или `blob:` | Откройте сохранённый HTML в обычном локальном браузере. Отметьте ограничение инструмента, не обходите его политику. |
| Неверно указаны факт или источник | Исправьте JSON и пересоберите карту. Проверка геометрии не устанавливает истинность. |

[Область проверки](verification.md) отдельно описывает установку, обнаружение, рендерер и запуски с моделью.
